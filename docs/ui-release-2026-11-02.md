# 2026-11-02 新版 UI 上线

## 问题与修正

上一轮公开体验发布只更新了 API / Worker 的额度与权限保护，线上 Web 镜像没有更新，因此访问者仍看到蓝色旧首页。这是部署范围遗漏，不是用户浏览器的问题。

本次单独发布已完成的前端：门户首页、旅行空间、行程流动视图、简化设置、移动端导航、公开体验额度和隐私提示，以及本地字体 / 原创视觉资产。开发用行程预览路由不包含在生产构建中。

## 发布边界

- 从已发布稳定提交建立隔离快照，只加入本次前端文件与入口缓存策略。
- 使用已发布的共享类型与后端接口完成构建，不引入本地未完成的后端或自适应微调实验。
- 仅构建并切换 Web 镜像。API、Worker、PostgreSQL、Redis、搜索桥接及账户额度保持不变。
- 页面入口 `index.html` 使用 `Cache-Control: no-store`；内容哈希静态资源可长期缓存。私有 API / 导出 / 图片响应继续保持不缓存。
- 保留旧 Web 镜像与配置，Web 健康检查失败时只回退前端，不回滚业务数据库。

## 验证

- TypeScript 检查和生产构建通过。
- 前端单元测试：48 passed。
- 浏览器端到端测试：35 passed，覆盖首页、表单、账户额度提示、行程列表、行程详情、设置、移动端、减少动画偏好及后台任务恢复。
- 发布后再核对公网入口的资源哈希、实际页面与缓存头，避免把本地截图当作线上验证。

首页图片为原创 AI 氛围视觉，不是实时景点照片；行程流文档截图使用演示数据。线上真实行程仍以接口返回的数据为准。

## 公网资源兼容处理

首次切换时检测到 CDN 会注入统计脚本，因此页面入口按“源站 HTML 完全一致 + 公网首方脚本 / 样式引用一致”验证，不把预期的统计脚本注入误认为旧版页面。

另发现旧版 SPA 对不存在的图片地址返回首页，CDN 将其缓存到该图片 URL。新版资源使用独立的 `assets/portal-ui-v1/` 路径，避免复用受影响的缓存项；新版 nginx 对不存在的 `/assets/` 资源返回 404，不再回落为首页。两次失败检查均自动回退，后台服务和业务数据库未受影响。
